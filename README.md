# Зерне — сайт кофейни (концепт)

Концепт сайта спешелти-кофейни в старом городе Гродно, сделан для портфолио. Кофейня вымышленная, фотографии сгенерированы нейросетью (Figma AI).

**Главная фишка — предзаказ навынос:** выбираешь напиток, молоко и сироп, указываешь время и забираешь без очереди.

## Что работает
- Карточки напитков с выбором молока, сиропа и количества.
- Корзина: на десктопе это панель сбоку, на телефоне — закреплённая плашка. Корзина сохраняется между страницами.
- Фильтры меню: категории, «Без молока», «Новинки».
- Оформление: время выдачи считается от текущего времени и часов работы, есть проверка имени и телефона.
- Экран «Заказ принят» с живым статусом заказа.
- Бронь столика с проверкой формы.
- Адаптивная вёрстка от 375 px, плавное появление блоков, учёт `prefers-reduced-motion`.

Заказы никуда не отправляются, оплата не проводится: это демонстрация интерфейса.

## Технологии
HTML, CSS и JavaScript без фреймворков и сборки. Шрифты Lora, Manrope и Caveat (Google Fonts).
